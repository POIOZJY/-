# 回复控制 · SillyTavern 扩展

面向 **DeepSeek V4 Pro 官方 API** 的消息控制面板。保留现有预设、角色卡和世界书，只在每次可见的 AI 回复请求中追加篇幅与剧情控制指令，并设置官方的真实思考强度。

## 安装

在 SillyTavern 的 **扩展 → 安装扩展** 中填写：`https://github.com/POIOZJY/-`，安装后刷新页面。要求 SillyTavern 1.18.0 或更高版本；在 **Chat Completion** 中选 **DeepSeek** 官方来源及 `deepseek-v4-pro` 模型。

## 使用

- 输入框左侧菜单、魔杖之后的第三个按钮是开关：点击开启或关闭，亮起表示开启。
- 右键按钮（手机长按）可打开快捷设置；扩展设置面板中也有同样的配置。
- 正文长度：快速 800～1000、均衡 1200～1600、剧情 1600～4000、长篇 4000～8000，或输入自定义目标字数（参考范围 ±5%）。
- 思考档位：快速 `low`、均衡 `high`、质量 `max`。界面中显示的约 30 秒、60 秒、3 分钟只是体验参考；插件不等待凑时、不按秒中断请求。
- “展开缩略剧情”会要求模型把用户概述的事件按顺序写成场景，而不是跳到概述之后。

插件对普通回复、重生成、滑动重抽和续写生效；不会干预后台静默生成和代写用户消息。关闭开关后不会更改请求。仅官方 DeepSeek V4 Pro 连接会被修改，其他 API 来源或模型不受影响。

## 冲突与限制

插件不会删除预设。若预设中的**篇幅**与所选档位冲突，本轮会要求模型以所选篇幅为目标；人设、世界观、文风等仍由预设决定。模型不一定每次严格照办。生成完毕后插件只对可见正文计数（不包括独立思考字段）；不在目标范围会提示，不会偷偷改写故事。自定义目标只是一项近似目标。

DeepSeek 将思考内容与正文分开返回；插件设置真实的 `reasoning_effort`，并为所选字数和思考强度预留输出 token 容量。**实际思考时长及正文长度无法精确保证**，更高的思考档位和更长的目标可能增加 API 用量和费用。使用流式输出时可在 SillyTavern 查看思考过程。

## 开发

核心逻辑在 `core.mjs`，界面及事件连接在 `index.js`。运行 `node --test tests/*.test.mjs` 验证关键请求行为。此扩展不需要服务器插件，也不直接接触 DeepSeek API 密钥。
